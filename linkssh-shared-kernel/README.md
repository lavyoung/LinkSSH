# LinkSSH Shared Kernel

该模块提供 LinkSSH 各限界上下文共同使用的少量稳定领域原语。

## 当前公开类型

- `DomainEvent`：领域事件的最小公共契约

## 允许的内容

- 稳定的领域事件基础契约
- 跨上下文通用且语义一致的值类型
- 与框架无关的基础抽象

## 禁止的内容

- Spring、数据库、SSH 或 AI SDK 类型
- HTTP 请求、响应和错误码
- PO、DTO、VO 转换工具
- 无明确领域语义的 `Utils`
- 仅被一个业务模块使用的类型

## 依赖规则

该模块不依赖其他 LinkSSH 模块，也不依赖应用框架。
