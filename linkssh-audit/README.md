# LinkSSH Audit

## 模块职责

`linkssh-audit` 负责系统审计上下文，包括：

- 记录用户操作
- 记录命令执行轨迹
- 记录 Agent 工具调用轨迹
- 记录治理与人工审批结果
- 提供安全追踪和审计查询能力

## 模块边界

本模块：

- 不参与命令风险判断
- 不决定命令是否允许执行
- 不改变其他业务模块的状态
- 不直接调用 SSH Client
- 不直接调用 AI 模型
- 不反向控制业务流程

审计失败的处理策略由应用用例或系统装配层决定，审计模块本身不承担主业务决策。

## 公开 API

当前 P0 阶段暂未定义公开 API。

后续公开契约放置在：

```text
com.lavyoung.ai.linkssh.audit
```

具体实现放置在：

```text
com.lavyoung.ai.linkssh.audit.internal
```

其他模块禁止访问 `internal` 包。

## 依赖关系

当前依赖关系：

```text
linkssh-audit
└── linkssh-shared-kernel
```

后续只有在实际消费其他模块发布的事件契约时，才能增加相应模块依赖。

审计模块不得成为其他业务模块的必需上游依赖，跨模块审计优先通过事件解耦。

## 数据原则

审计记录应满足：

- 关键操作具有稳定标识
- 时间使用明确的时间戳
- 敏感字段必须脱敏
- 不记录明文密码、私钥或访问令牌
- 已产生的审计事实原则上不可修改
